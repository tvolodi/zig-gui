## Milestone 20 — GPU backend seam — Completion Summary

### What was done

1. **Fixed `-Dgpu` build option wiring** — the option was defined but silently discarded
   (`_ = b.option(...)`) and never passed to any module's `build_options`. Now it's captured
   into `gpu_selected`, added to `build_options` as a `BackendKind` field, and wired to
   `mod10_gpu_backend`. Module root changed from `src/10/types.zig` to `src/10/backend.zig`
   so the comptime dispatch compiles.

2. **Added configure-time target validation** — RJ0 AC4: `zig build` rejects `-Dgpu=metal`
   on Windows / `-Dgpu=vulkan` on macOS at configure time with a clear `@panic` message.

3. **Fixed `initPipelines`/`initQuadPipeline` naming** — `initPipelines` is the seam name;
   `initQuadPipeline` now delegates to it (backward compat for frozen acceptance tests).

4. **Fixed RJ0 spec mode table transposition** — the requirement doc listed modes
   "1 = bordered rect, 2 = glyph" but both the shader and `types.zig` agree on
   "1 = glyph, 2 = bordered rect". Corrected.

5. **Fixed RJ0 `createSurface` return type** — changed from `PlatformError!*anyopaque`
   to `PlatformError!Surface` to match RJ5 and the implementation.

6. **Added glossary entries** — `BackendKind`, `BackendError`, `Caps`, `AtlasHandle`,
   `AtlasHandles` added to glossary.md's V2 terms section.

7. **Added shader-mode parity test** — RJ0 AC3: the smoke test documents the known
   8-mode count (modes 0-7, mode 8 deferred).

8. **All existing tests pass** — `zig build` succeeds, all acceptance and unit tests
   (modules 02-08, 10, app tests) pass with zero regressions.

### What is deferred (by design)

- `drawFrame` signature stays `*const anyopaque` not `AtlasHandles` — the frozen
  09.acceptance_test.zig calls `drawFrame(&.{}, &gpu_atlas)` with a raw pointer.
  The `AtlasHandles`-typed signature will land when a second backend is implemented
  (M21/M22/M23), at which point the contract amendment will update both the seal and
  the acceptance test call sites.

- Surface layer files (`src/01/surface*.zig`) don't exist as separate files — the
  `Surface` union and `createSurface` dispatch live inline in `src/01/types.zig`.
  Extraction deferred to when a second backend (Metal/DX12/WebGPU) needs platform-
  specific surface handles.

- Visual regression baseline (RJ1 AC2) — requires a pre-refactor screenshot to compare
  against. No such baseline exists in the codebase. The `zig build visual-check` command
  exists and passes a non-blank-frame test.
