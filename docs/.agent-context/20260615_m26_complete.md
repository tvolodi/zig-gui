## Key implementation decisions

- `Color09` (u8 fields) used throughout mod13 — matches `DrawCommand` payload types, not the f32-based `Color`.
- `Rect09` fields (`w`/`h`) used for `ChartFrame` plot rects — matches `src/01/types.zig:Rect09`.
- `std.ArrayListUnmanaged` with `.empty` init and `append(allocator, ...)` — required by Zig 0.16 API.
- `{d:.4}` format specifier for tick labels — `{d:.4g}` is invalid in Zig's std.fmt.
- `mod01_platform` GPU links propagate transitively to `unit_13` test binary via module import.
