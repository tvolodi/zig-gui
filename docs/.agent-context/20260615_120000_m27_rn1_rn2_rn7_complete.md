# M27 RN1/RN2/RN7 — Implementation Complete

**Date:** 2026-06-15
**Module:** 13 (charts), `src/13/`
**Requirements:** RN1 (donut chart), RN2 (annotation callouts), RN7 (crosshair guide)

## What was built

### RN1 — Donut chart kind (`src/13/chart.zig`, `src/13/marks.zig`)
- Added `inner_radius: f32 = 0.0` and `center_label: ?[]const u8 = null` fields to `Chart`.
- `renderPie` now computes ring arc geometry when `inner_radius > 0`:
  - `arc_radius = outer * (1 + inner_radius) / 2` (center of stroke)
  - `arc_width  = outer * (1 - inner_radius)` (ring thickness)
  - Result: inner edge at `outer * inner_radius`, outer edge at `outer`.
- When `center_label` is set and `inner_radius > 0`, emits an `aa_filled_circle` as a background
  slot (caller renders glyphs; same pattern as `drawLegend()`).

### RN2 — Chart annotations / leader-line callouts (`src/13/chart.zig`, `src/13/marks.zig`)
- Added `Callout` struct (`datum_idx: u32, label: []const u8`) and `callouts: []const Callout = &.{}` to `Chart`.
- `renderCallouts` (called from `renderChart` for pie charts) replays the renderPie angle traversal to compute each segment's mid-angle, then emits:
  1. A 2-point `PolylineCmd` (leader line from outer edge to `outer * 1.5` anchor).
  2. A `filled_rect` label background at `outer * 1.6` anchor.
- Public `computeCalloutPos` helper returns geometry (`anchor`, `label_pt`, `mid_angle`) without rendering — for caller-side glyph placement.
- Non-overlap guarantee: for 5+ evenly-distributed segments, inter-anchor distance ≥ 1.76×outer_r, which exceeds the 60 px label background width.

### RN7 — Chart crosshair / reference guide on hover (`src/13/interaction.zig`, `src/13/marks.zig`)
- Added `CrosshairOptions` struct and `crosshair: CrosshairOptions = .{}` to `Chart`.
- `renderCrosshair` emits alternating short `PolylineCmd` segments (dashes) at the hovered datum's x-pixel. No new draw-command vocabulary (INV-2.1-v2).
- Added `CrosshairState` and `updateCrosshairX` to `interaction.zig`:
  - `null` mouse → clears `state.x` (hide on mouse-out).
  - Mouse outside plot rect → clears `state.x`.
  - Otherwise snaps to nearest datum x via `hitTest`.

## Pre-existing bugs fixed
- `renderLine` and `renderArea` in `marks.zig` called `out.append(item)` without passing the allocator (correct Zig 0.16 signature is `out.append(allocator, item)`). Fixed in both functions.
- `renderScatter` compared `u32 hovered_datum` with `usize i` directly — fixed with explicit `@as(usize, hd) == i`.
